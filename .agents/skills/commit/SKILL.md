# 커밋

## 승인 경계

사용자가 현재 변경의 커밋을 명시적으로 요청한 경우에만 실행한다. 승인 전에는 상태와 커밋 제안만 보고한다.

## 절차

1. `git status --short`, `git diff`, `git diff --cached`, 최근 커밋 형식을 확인한다.
2. 비밀값, `.env`, 인증서, 관계없는 사용자 변경은 스테이징하지 않는다.
3. 요청 범위의 파일만 명시적으로 스테이징한다.
4. `git diff --check`와 관련 테스트를 실행한다.
5. `<type>: <한국어 설명>` 형식으로 한 논리 단위만 커밋한다.

허용 type은 `feat`, `fix`, `refactor`, `test`, `chore`, `docs`다. `--amend`, force 옵션, AI 작성자 trailer는 사용자가 별도로 요구하지 않는 한 쓰지 않는다.
