# ADR-0003: 가게 댓글 조회·작성 API를 현재 범위에서 제외

- 상태: Accepted
- 결정일: 2026-08-21

## 배경

Issue #207은 가게 댓글 조회·작성 API의 계약 확정과 구현을 제안했다. 프로젝트 결정에 따라 해당 기능은 현재 프로젝트에서 진행하지 않는다.

## 결정

현재 프로젝트 범위에 가게 댓글 조회·작성 API를 포함하지 않는다.

## 영향

- 가게 댓글 조회·작성 API의 method/path, 요청·응답, 인증·권한, 페이지네이션, 보존 및 오류 계약을 이번 범위에서 확정하거나 구현하지 않는다.
- Issue #207은 종료 상태로 유지한다.
